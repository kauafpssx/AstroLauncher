# AstroLauncher

Launcher de Minecraft moderno — Rust + Tauri no backend, React + shadcn/ui no frontend.

Documentação completa em [`docs/`](docs/README.md).

## Stack

- **Backend:** Rust, Tauri 2
- **Frontend:** React 19, TypeScript, Vite, Tailwind CSS 4, shadcn/ui
- **Estado:** Zustand
- **Banco:** SQLite (rusqlite)

## Desenvolvimento

```bash
npm install
npm run tauri dev
```

## Build

```bash
npm run tauri build
```

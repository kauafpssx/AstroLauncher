# 🆘 Suporte

Precisa de ajuda com o AstroLauncher? Aqui estão os caminhos certos para cada tipo de dúvida.

## 🐛 Encontrei um bug

1. Pesquise nas [issues existentes](https://github.com/kauafpssx/AstroLauncher/issues). Seu problema pode já ter sido reportado, e até resolvido.
2. Se não encontrar nada, abra uma nova issue usando o [template de bug report](https://github.com/kauafpssx/AstroLauncher/issues/new?template=bug_report.yml). Inclua:
   - Versão do launcher (ex: `0.2.0`)
   - Sistema operacional (ex: Windows 11)
   - Versão do Minecraft e loader (Vanilla, Fabric, Forge...)
   - Logs do launcher, se possível
   - Passos para reproduzir o problema

> 🔒 **Problema de segurança?** Não abra uma issue pública. Siga o processo descrito em [`SECURITY.md`](SECURITY.md).

## 💡 Tenho uma sugestão

Use o [template de feature request](https://github.com/kauafpssx/AstroLauncher/issues/new?template=feature_request.yml) e descreva:

- O problema que você quer resolver
- A solução que você imagina
- Alternativas que você já considerou

- [README](README.md): visão geral, funcionalidades e instruções de build

## 🤝 Quero contribuir

O [CONTRIBUTING.md](CONTRIBUTING.md) tem tudo: ambiente de desenvolvimento, padrões de código, convenção de commits e fluxo de Pull Requests.

## 📦 Quero baixar uma versão estável

As versões estáveis ficam na página de [Releases](https://github.com/kauafpssx/AstroLauncher/releases). O launcher também verifica e baixa atualizações automaticamente.
